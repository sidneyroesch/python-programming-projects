# Python Programming Projects

A collection of beginner-level Python programming projects developed as part of my Programming 1 studies.

These projects demonstrate my developing understanding of programming fundamentals, problem-solving, logical thinking and writing structured Python code.

## Projects

### 1. Banksimulatorn – Banking Simulator

A console-based banking simulation that allows users to perform basic banking operations.

**Features:**
- Deposit money into an account.
- Withdraw money with balance validation.
- Display the current account balance.
- View a transaction history.
- Simulate savings growth using annual deposits and interest rates.
- Handle invalid numerical input.

**Programming concepts:**
- Functions
- While loops and conditional statements
- Lists
- User input and input validation
- Arithmetic operations
- String formatting

**File:** `Banksimulatorn-main.py`

### 2. Betygsstatistik – Grade Statistics

A program that collects scores in five subjects, converts them into letter grades and calculates statistics based on the results.

**Features:**
- Enter scores in five different subjects.
- Convert numerical scores into grades A–F.
- Display individual subject results.
- Calculate the total and average score.
- Count the number of each grade achieved.

**Programming concepts:**
- Functions
- Lists
- For loops
- Conditional statements
- List operations
- Mathematical calculations

**File:** `betygsstatistik-main.py`

### 3. Växelprogrammet – Change Calculator

A program that calculates the change a customer should receive after making a purchase.

**Features:**
- Enter the purchase price and payment amount.
- Calculate the amount of change.
- Apply rounding to the calculated change.
- Break down the change into Swedish banknotes and coins.
- Handle incorrect numerical input.

**Programming concepts:**
- Variables and data types
- User input
- Conditional statements
- Arithmetic operations
- Integer division and modulo
- Type conversion

**File:** `Växelprogrammet-main.py`
